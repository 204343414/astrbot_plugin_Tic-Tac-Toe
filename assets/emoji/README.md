# 牛角棋的棋子贴图

字体里没有彩色 emoji（Pillow 画 NotoColorEmoji 会得到空白），所以棋子和牛都走贴图。

| 文件 | 对应 | 出处 |
| --- | --- | --- |
| `man.png` | 👨 赶牛的人 1 | [OpenMoji](https://openmoji.org/) `1F468` |
| `woman.png` | 👩 赶牛的人 2 | OpenMoji `1F469` |
| `cow.png` | 🐮 牛 | OpenMoji `1F42E` |

三个都从 OpenMoji 的 618×618 彩色 SVG 导出的 PNG 缩到 192×192，透明底。
