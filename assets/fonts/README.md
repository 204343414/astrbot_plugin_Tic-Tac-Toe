# 打包字体

`wqy-microhei.ttc` —— 文泉驿微米黑，**Apache License 2.0**（见 `LICENSE_Apache2.txt`，
作者名单见 `WQY-AUTHORS.txt`）。5.2 MB，覆盖 Unicode 5.1 全部统一汉字
（U+4E00–U+9FC3，即 GBK 全集）以及拉丁、假名、谚文。

## 为什么直接打进插件

图片棋盘上要写玩家昵称、"轮到你落子"这类文字。之前的做法是扫描系统字体，
找不到中文字体就整块降级成英文——这在 Docker 部署里几乎是必然发生的
（官方镜像不含中文字体），结果就是"为什么我的棋盘是英文的"。

让用户去 `apt-get install fonts-noto-cjk` 是把一个 5 MB 的问题推给用户。
Noto Sans CJK 单个 .ttc 就有 19 MB，微米黑只要它的四分之一，覆盖度对
"昵称 + 界面词"这个用途完全够用，许可证也允许再分发。

系统字体仍然优先：若宿主机装了 Noto/思源，观感更好，用系统的；只有找不到时
才回落到这个内置字体。**任何情况下都不再降级成英文。**
